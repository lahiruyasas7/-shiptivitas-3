# Three Actionable Ideas

## 1. Guided first Kanban move

### Hypothesis

Users who see an immediate guided prompt to move their first card from backlog to in-progress will understand the Kanban workflow and return more often.

### Expected Impact

Increase daily active users by 10–15% by turning one-time visitors into users with an initial completed workflow.

### What the feature is

After creating or viewing a board, show a one-time guided tooltip pointing from a backlog card to the in-progress column. Include a short success confirmation after the first drag.

### Optional user flow

1. A new user opens the Kanban board.
2. The interface highlights one backlog card and the in-progress column.
3. The user moves the card.
4. A success message confirms that the first workflow is complete.
5. The guide closes and is not shown again.

## 2. Inactive-user return notifications

### Hypothesis

A targeted reminder will bring users back when a card they own or recently moved is updated or awaiting a status change.

### Expected Impact

Increase the 7-day active-user rate and lift daily active users by 5–10% through re-engagement.

### What the feature is

Add optional email or in-app notifications for card assignments, approaching due dates, and cards left unchanged for a configurable period.

### Optional user flow

1. A card is assigned or remains inactive past the configured period.
2. The system creates a relevant notification.
3. The user opens the notification.
4. The app opens the affected card or board.
5. The user updates the card status or confirms the next action.

## 3. Fast-status actions and bulk moves

### Hypothesis

Reducing the number of interactions needed to update card status will encourage more frequent use of the Kanban board.

### Expected Impact

Increase the status-change rate by 15–20%, because the data shows substantial movement after the Kanban feature was introduced.

### What the feature is

Add right-click or keyboard status menus and allow users to select several cards and move them to the same status at once.

### Optional user flow

1. The user selects one or more cards.
2. The user opens a status menu or keyboard shortcut.
3. The user chooses a new status.
4. All selected cards move to that status.
5. The interface shows an updated board and a single success notification.
